本批把十二條既有閱讀路線由全部攤開，改為一次選讀一條；另加四篇入門順序：背景 → K 棒證據 → R 與部位 → 事前／事後紀錄。排序與逐篇任務為本站編排，不是 Brooks 或其他作者官方課綱。

## 行為與相容性

- `dist/reader-paths.js` 提供純函式：準備路線、計算已讀數與第一篇未讀、產生安全 HTML。它不存取儲存空間、不發送網路請求、不改寫傳入紀錄。
- `reader.js` 在目錄載入及已讀／收藏／匯入更新後，以現有 `state.records` 更新導航。切換路線只改本頁記憶體中的選擇，不保存新偏好或變更原備份格式。
- 全部已讀時提供重讀入口；收藏、筆記、載入或開啟文章都不自動算已讀。已讀標記不能代替理解、測驗或交易驗證。
- 原 `reading/index.json` 的十二條路線及 62 篇文章不變；兩組筆記鍵、`reader-state.js`、匯出／匯入行為不變。
- 新樣式 `learning-paths.css` 延續單欄、大字、留白與黑體重點，手機保留可操作的原生選單。若導航模組不可用，原十二條連結仍有閱讀器回退呈現。
- 文章原有「整理圖」「練習」「圖例與測驗」「來源與授權」仍按各篇實際內容顯示；導航任務不新增測驗數或虛構成效。

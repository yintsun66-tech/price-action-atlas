# 教材易讀性與每日校讀

2026-11-10 起，依全站審查採用以下編輯流程。新版以既有來源為基礎整理，不將編排修訂計為新的來源實讀或全文翻譯。

## 教學與導覽

- 主要入口：第一次來、接著學下去、帶問題查找。六階段十八篇為共同主線；十二練習單元、四十八任務搭配各階段使用；十三條延伸路線按需展開。
- 每篇先回答問題、標示一項核心觀念及可完成的第一步。深度校讀時加入同一組數字的圖／表、反例、自測題、可展開答案與理由。
- 三篇首輪深度範例為 brooks-context-first、pp2-signal-gap、flow-footprint；其餘五十九篇先套共用閱讀層次，後續逐批深入校讀，不宣稱全部已逐句改寫。
- 長文保留原章節 ID；進階延伸可收合，章節目錄跳轉時自動展開。影響結論的限制必須留在相關段落。
- 保留大字、寬鬆行距，縮短首屏操作區；每段一件事，重點適量粗體。新增算例不替換原作者例子，需標為本站原創。

## 翻譯與資料一致性

- Last、Close、stop、tick、Bid、Ask 等多義詞禁止盲目全站取代，依平台與上下文說明。Delta、CVD、FVG 等保留可搜尋的英文縮寫，首次出現提供繁中解釋；術語頁保存完整對照。
- 原英文、來源範圍、發布與查核日、Brooks 單元與關係保持。文章修訂日不能冒稱重新查核來源。
- 圖、表與附近正文盡量使用相同數字。完整後續路徑和當時可知圖分開，先作答再揭露。既有另組資料的圖不得移除原揭露。
- 顯示數量由閱讀目錄與圖解資料產生。網站發布日、文章修訂日及來源查核日分列；歷史「本批」改成確切日期。

## 每天十點

沿用原 heartbeat，不建立第二份排程。先同步 main，再選少量既有文章進行語境校讀、圖文對應及理解流程改善；完成後再蒐集少量具新增學習價值的中英文第一手與公開社群材料。新文去重、實讀範圍、引用授權、評價限制及版本發布遵循 daily-content-workflow.md 和 versioning.md。

每輪紀錄實際改動、尚待校讀、未採用與取得失敗。驗證重建穩定、文章 ID／筆記相容、答案算術、來源保留、進階展開、目錄跳轉、桌面與窄版。無實質改善不為排程升版。

# 原創圖解與四流派比較 · 2026-10-28

新增威科夫、ICT、訂單流各三篇與流派比較三篇，共十二篇繁中導讀及三十六題測驗。全庫現在五十四篇、九十九題、九條路線，五十四篇皆有對應整理圖，共六十張原創 SVG。原九個逐根回放保留，另有全路徑整理圖；完整圖可能揭露後續，盲測仍從原回放介面開始。

## 圖解範圍

- 以文章的價格路徑、統計計數、切棒時間、風險算式或研究流程選圖。不是用同一根通用 K 棒重複裝飾五十四篇。
- 圖形使用本站合成數字；原九個回放的靜態圖使用既有合成 OHLC。正文與回放若為不同例題，在圖說分開。
- FVG 多頭圖與正文均為 H1=101、L3=102.5，第三棒收線才確認；中間棒穿越該區，不表示無成交。
- Footprint 範例同一價位 Bid 120、Ask 180，Delta +60；CVD 範例 +60、−20、+10，各重置方式另列；DOM 100→40 有撤60與增20再成交80的不同路徑。
- 舊四十二篇 article JSON 不改；圖的段落綁定放在獨立 `reading/figures.json`／`figures.js`。所有圖可開啟 SVG 放大；窄畫面在圖框內左右捲動。
- 兩篇 CC BY-SA 授權節譯頁新增的原創圖，也標明相同授權及圖為本站新增，沒有重畫來源原圖。

## 新教材與來源

每篇的來源與授權分頁列出原作者、英文網址、查核日期、實際取得範圍及使用界線。原始來源公開可讀不等於可重刊全文；本批以短摘要、必要定義及本站原創的研究例子組成。

威科夫：StockCharts ChartSchool、Wyckoff Analytics／Bruce Fraser／John Colucci 等當代公開教學。沒有聲稱讀完威科夫原版完整課程。Spring／UTAD 不必然出現，綜合人是思考模型，因果法則不能換成盤整時間必定對應漲幅。TMF 既有量能差異未釐清前不確認價量條件。

ICT：官方網站、官方 2022 Mentorship 播放清單、Episode 6、FVG／Orderblocks 主題影片入口。僅取得標題與公開描述，未取得官方逐字稿，未聲稱完整觀看。三棒 FVG、MSS 與位移門檻明列為本站最小研究定義；OB 不證明機構倉位。NIST 官方文件核對時區與 DST，紐約09:30不等同微台日盤開盤。

訂單流：Sierra Chart Numbers Bars／CVD、CME MBO FAQ、Bookmap 公開教學、Binance 官方串流文件與 TAIFEX 成交頁／行情手冊。這些能核對格式、計算或觀察範圍，沒有替策略提供獲利證明。成交、可見待成交委託及分析推論分開；單一 Binance 商品／串流不能代表全 BTC 市場。

Brooks：以官方公開價格行為文章及 Main 12A〈市場週期〉、15A〈突破〉作相關補讀。Main 與 Forex 共用的基礎部分；沒有把威科夫、ICT 或訂單流自有教材改稱 Brooks 原課。既有十八項機率註記與原典限定詞保留。

## 網頁功能

`#schools` 提供四組介紹、十個面向的比較表、同圖四種觀點與資料層規劃選單。所有比較為本站整合分析，沒有以熱門度建立績效排名。

同圖只含指定價位順序，沒有完整 OHLC、量或訂單流；切換到 ICT 不能憑折線產生 FVG，切換到訂單流也不會生成真實 Delta。資料層選單只表示研究者打算具備的資料，沒有連接行情或下單。

閱讀頁在正文指定段落顯示整理圖，另有「整理圖」分頁。新增來源與批次篩選，保留原 ID、原筆記儲存鍵與原四十八項任務。新圖採本機 SVG，未啟用外部追蹤、資料庫、行情訂閱或付費擴容。

## 可重建與驗證

- `node scripts/build-study-figures.cjs`：依合成資料重建六十張圖與圖索引。
- `node scripts/build-schools-library.cjs`：重建新目錄、九條路線與比較專區。

- `node tools/check_schools_http.cjs <owned-local-url>`：逐一檢查文章、圖片及本地資產 HTTP 回應與位元組；測試伺服器使用後停止。

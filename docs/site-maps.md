# 網站導覽與學習地圖

日期：2026-10-31（Asia/Taipei）。本站編排的導覽及練習順序，不是 Brooks、方方土或其他講師的官方課綱。

## 使用方式

- `#site-map`：六個用途分組，連至十六個既有／新增專區。專區搜尋比對名稱、說明及中英文關鍵字，支援多詞；不是文章全文搜尋。無結果時可清除或轉至閱讀庫。
- `#learning-map`：沿用原有六階段名稱，精選十八篇不同文章。每階段三篇，顯示閱讀時間、已讀標記與練習成果；階段不鎖定。上方推薦第一篇未讀，全部已讀後改為複習提示，不自動宣稱精通或可實盤。
- 四個延伸入口分別連到 Brooks、威科夫、ICT 與訂單流的既有入門文章；閱讀庫的十三條路線保留。
- 首頁、主要導覽與閱讀視窗都可回兩張地圖。既有 `#map` 維持原四十八項任務的六階段總覽，`#plan` 維持日期、投入時間與課程補讀。十八篇已讀和四十八項任務分開計算。
- 二十筆歷史更新連結收在可展開的更新紀錄，文字及連結全部保留。

## 實作與相容性

內容檔 `scripts/site-maps.json`；以 `node scripts/build-site-maps.cjs` 產生首頁區塊、`site-maps-data.js`、`site-maps.js`、`site-maps.css`。原始 CSS 及執行檔分別為 `scripts/site-maps.css`、`scripts/site-maps-runtime.js`。部署版 `20261031maps1`。

閱讀器只增加可選的更新／失敗通知 hook，以及初次深連結的捲動定位。地圖不自行讀寫 localStorage、不另取文章或來源、不建立帳號或新進度格式；以閱讀器當前 `state.records` 及既有目錄更新畫面。筆記、收藏及已讀變更仍由原閱讀器處理。新模組缺少時原閱讀器照常運作；目錄取得失敗時保留可點選的文章及完整六階段靜態清單。

62 篇文章、68 張原圖、十二條原目錄路線加一條入門路線、全部來源與翻譯紀錄、兩組進度鍵皆保留。沒有新增外部引用或增加翻譯完成數。僅首頁、閱讀器整合及更新紀錄有既有部署檔變更，另新增三個地圖資產。

後續翻譯流程仍執行翻譯清單 → 中文呈現；`enable-chinese-first.cjs` 偵測地圖已安裝時會最後重建地圖，保留導覽、收合更新及閱讀器資產版本。不要重跑早期完整首頁生成器覆蓋新區塊。獨立建圖可直接執行本批生成器。

## 驗證

- `tools/check_site_maps.cjs`：11 項檢查涵蓋目的地、既有內容位元組、只讀進度、全讀狀態、多詞搜尋、轉義及重建一致。
- `tools/check_site_maps_reader.cjs`：原 71 項回歸，加兩項以真正閱讀器函式、模擬 DOM 與隔離記憶體儲存檢查推薦更新與筆記保留，共 73 項。既有閱讀與來源回歸 43 項亦通過。
- 瀏覽器以唯讀方式檢查搜尋、空結果、重設、六階段切換、文章開啟與返回地圖，無 console error。修正多行文章標題的點擊區為整塊，避免點到行間空白。
- 390px 模擬下兩張地圖與文章視窗無水平溢出；寬螢幕顯示三欄用途卡及六欄階段。暫時 viewport 測試後已重設。
- 自動審核拒絕會寫入實際筆記及已讀的瀏覽器測試，因此未執行；改以隔離的合成記憶體資料驗證，未透過其他方式寫入使用者學習紀錄。

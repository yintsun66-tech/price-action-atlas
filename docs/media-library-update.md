## 結構與操作

`dist/media/catalog.json` 與 `dist/media/books.json` 保留完整研究欄位。`scripts/build-media-library.cjs` 產生首頁兩個獨立專區，以原始閱讀文章 ID 連回教材。執行方式：

```text
node scripts/build-media-library.cjs
```

`dist/media.js` 提供本機搜尋、語言／形式篩選、書籍排序、展開及卡片深連結。未啟用 JavaScript 時仍呈現完整靜態連結與中文內容。不新增或修改任何 localStorage 鍵。

沿用原有蘋果風格、大字與粗黑重點；新增版面在 850px 及 520px 下調整欄數、間距與控制項寬度。來源碼的響應式規則不能取代實際瀏覽器視覺驗收。

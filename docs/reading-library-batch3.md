3. 研究登記簿：保留失敗版本與已接觸資料，不冒充 PBO／CSCV 實作。
4. 停損觸發與實際成交：自編跳空路徑，區分價格保護與未成交風險。
5. 日盤、切棒與契約月份：核對微台一般日與到期契約最後交易日的收盤差異；BTC 合成為本專案協定。
6. 訪談變成研究問題：Grimes／Nison 的公開介紹與本站延伸練習分開。
7. 第二次進場標記一致性：盲標、未決分類、覆蓋範圍與失敗反例。
8. 拒絕清單：操作修正與新增策略濾網分開，保留取消後獲利的反例。
